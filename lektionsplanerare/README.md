# Digital lektionsplanerare

En separat prototyp under Musikportalen, avsedd för lärarens planering, genomförande och reflektion i praktisk-estetiska ämnen.

## Funktioner
- Skapa, redigera, ta bort och söka lektionsplaneringar.
- Datum, årskurs 3–9, ämne, status, mål, lektionsupplägg, stöttning, observationer, reflektion och nästa steg.
- Kognitionsvetenskapliga reflektionsstöd, inte verifierade litteraturcitat.
- Lokal lagring i webbläsaren och JSON-export/import för manuell säkerhetskopia.

## Testa
Öppna `index.html` i webbläsaren eller, om GitHub Pages aktiverats, besök `/Musikportalen/lektionsplanerare/`.

## Säkerhet och begränsningar
**Ingen inloggning, server eller säker central datalagring finns i denna version.** Använd inga elevnamn, identifierbara observationer eller känsliga personuppgifter. Webbläsarlagring är enbart för demonstration och kan raderas eller läsas av andra med tillgång till samma webbläsarprofil. Exportfiler behöver skyddas. Innan skarp skolanvändning krävs huvudmannens godkännande, säker autentisering, åtkomstkontroll, lagring och personuppgiftshantering.
